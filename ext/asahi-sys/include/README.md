`asahi_drm.h` and `drm.h` are the exact headers installed on the M2 Max (Asahi Linux) used by
Apple-M2-Playground's `results/2026-10-04-device-params` query, which matches the running kernel driver.
Both are MIT licensed (see their headers). `src/lib.rs` is generated from them by `zluda_bindgen asahi`.
